Pill-shaped keys with a 3px bottom edge that sink as you press them — playful, but softer than a block key.

- **Primary** (`primary` / `primary-edge`) — one per screen: *Start session*, *Save take*, *Continue*.
- **Secondary** (`tonal` teal tint, `success` label) — *Listen back*, *Record again*.
- **Sun** — rewards only: *Collect notes*.
- **Disabled** — `surface` until there's something to save.
- **Link** — ink text with a teal underline: *Skip for today*.
- Fredoka 18/600, sentence case; 52px with edge; full width on a phone. Recording uses `RecordButton`.
