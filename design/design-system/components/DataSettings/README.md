Form fields and the guest-data controls for the Settings page.

- Fields: visible `<label>` above, 48px control, 2px `line` border, hint in `muted` below, error in `danger` under the field.
- **Delete my data** (spec requirement): the confirmation opens inline in a `danger-tint` bordered zone, not a modal. It states exactly what goes (recordings, profile, plan, streak, notes) and that it can't be undone.
- The danger key is the only place a red button appears; *Keep my data* is the secondary next to it.
