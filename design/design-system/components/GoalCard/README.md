Single-choice goal cards on the start screen, built on the same pressable option recipe as `ExerciseCard`.

- `role="radiogroup"` with `role="radio"` cards; selected = `primary` border, edge and tint.
- Question as a heading (`h2`), 3–4 options, then a full-width *Continue* that stays disabled until one is picked.
- Icons are drawn line icons (2.2 stroke), never letters, emoji or Unicode glyphs.
- Goals match the API enum: `clear_speech`, `expressive_voice`, `confident_delivery`; no medical or "fix" wording.
