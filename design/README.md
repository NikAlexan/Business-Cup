# Resonance — дизайн фронтенда

Дизайн веб-клиента для бэкенда этого репозитория: дизайн-система, адаптивные экраны (десктоп / планшет / телефон), карта переходов и предложения к API.

«Resonance» — рабочее название. Интерфейс на английском (США), документация на русском.

## Экраны

1. **Первый визит:** `Main` (цель + согласие) → `MicCheck` (разрешение + условия записи) → `Record` (3 задания) → `Analyzing` → `Profile`. Ошибки: `MicBlocked`, `Rerecord`.
2. **Подписка (Stripe test mode):** `Paywall` → Stripe Checkout → `PaySuccess` / `PayCanceled`; `Terms`.
3. **Каждый день:** `Home` → `Exercise` → `Done`; `Progress`, `CheckIn`, `Settings`.

Цифры, даты и [PRICE] на макетах — примеры и заглушки, не данные.

## Источник

Живые версии: дизайн-система и холст с экранами в Claude (артефакты «Resonance» и «Resonance — основные экраны»). Файлы здесь — снимок для разработки; при расхождении правьте сначала дизайн-систему.
